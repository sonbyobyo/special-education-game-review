# 입력·의미 구조

각 항목의 근거 지위·적용 조건·예외를 함께 읽는다. 기준 원문은 2026-10-05 조사에서 가져왔고 제품 합격 판정은 포함하지 않는다. [출처 원장](sources.json)에서 source_ids의 URL·절·판본·한계를 확인한다. 최신 개정, 법적 적용 또는 세부 수치가 결과를 바꾸면 해당 발행기관 원문을 다시 확인한다.

## A01 전체 키보드 흐름

- 분류: 공통
- 적용조건: 웹 상호작용
- 근거지위: WCAG 2.1.1 A
- 검사방법: 시작, 수행, 도움, 취소, 완료를 키보드로 실행
- 통과조건: 키보드 경로로 핵심 기능을 완료
- 예외: 기저 기능의 경로 본질 예외만 별도 기록
- 검증주체: 검수자
- 중요도: 핵심
- source_ids: S77

## A02 단일 포인터 비드래그 대안

- 분류: 조건부
- 적용조건: 드래그 활동
- 근거지위: WCAG 2.5.7 AA
- 검사방법: 선택 후 목적지 누르기 등을 직접 포인터로 실행하고 대상·목적지·수정 등 같은 기능을 사용자가 선택하는지 비교
- 통과조건: 드래그 없이 같은 기능을 완료
- 예외: 본질적 드래그 등 명시 예외; 키보드만으로 대체 통과하지 않음
- 검증주체: 검수자
- 중요도: 핵심
- source_ids: S08

단순 자동 배치와 사용자 목적지 선택을 구분한다. A02의 기능 동등성과 G01/G02의 학습 행동 보존은 별도 판단이다. [활동 검사 절차](activity-checks.md)에 따라 equivalence를 기록하며 목표 미확인 자체를 WCAG 불합격으로 만들지 않는다.

## A03 포인터 취소

- 분류: 조건부
- 적용조건: 포인터로 작동하는 컨트롤
- 근거지위: WCAG 2.5.2 A
- 검사방법: 누름, 떼기, 영역 밖 취소, 되돌림을 시험
- 통과조건: 취소 또는 복구 조건을 충족
- 예외: 본질적 down 동작 등 표준 예외를 기록
- 검증주체: 검수자
- 중요도: 높음
- source_ids: S11

## A04 터치 목표 크기와 간격

- 분류: 조건부
- 적용조건: 포인터 목표
- 근거지위: WCAG 2.5.8 AA
- 검사방법: 실제 CSS 목표 크기, 간격 예외를 측정
- 통과조건: 24 CSS px 크기 또는 명시된 간격 등 예외를 충족
- 예외: 44 CSS px AAA와 구분; 개별 기기의 접근 요구를 추가 확인
- 검증주체: 검수자+실기기
- 중요도: 높음
- source_ids: S09;S10

## A05 스위치 스캔 실제 경로

- 분류: 조건부
- 적용조건: 스위치 스캔 지원을 주장하거나 필요함
- 근거지위: 보조공학 운영 검증 제안
- 검사방법: 실제 OS, 기기 스캔으로 시작, 응답, 도움, 취소, 완료를 수행
- 통과조건: 합의한 설정에서 전체 경로를 수행
- 예외: 키보드 통과를 스캔 통과로 치환하지 않음
- 검증주체: 실기기+학생관찰
- 중요도: 핵심
- source_ids: S12;S27

## A06 보이는 논리적 초점

- 분류: 조건부
- 적용조건: 키보드 컨트롤
- 근거지위: WCAG 2.4.3 A, 2.4.7 AA, 2.4.11 AA; KWCAG 6.1.2
- 검사방법: 초점 순서, 가림, 사라짐 등 모든 상태를 실행
- 통과조건: 현재 컨트롤과 다음 경로를 식별 가능
- 예외: 기본 CSS 존재만으로 실행 통과를 판정하지 않음
- 검증주체: 검수자
- 중요도: 핵심
- source_ids: S01;S78;S21

## A07 접근성 이름, 역할, 상태

- 분류: 공통
- 적용조건: 네이티브 및 커스텀 컨트롤
- 근거지위: WCAG 4.1.2 A
- 검사방법: 접근성 트리와 상태 변경을 확인
- 통과조건: 조작의 목적, 현재 상태, 변경 정보를 노출
- 예외: 실제 화면 낭독 상호운용은 별도 시험
- 검증주체: 검수자+보조기기
- 중요도: 핵심
- source_ids: S79

## A08 Canvas 활동의 동등 정보와 조작

- 분류: 조건부
- 적용조건: Canvas, WebGL 학습 활동
- 근거지위: HTML 표준의 동등한 기능·목적 대체 콘텐츠 요구 및 포커스 영역 대응 권고; WCAG 4.1.2 A
- 검사방법: 그려진 대상, 상태, 핵심 조작의 대체 표현을 확인
- 통과조건: 핵심 활동을 정보 및 조작 경로로 완료 가능
- 예외: 단일 aria-label은 객체 노출 증거가 아님; 대체가 목표를 바꾸면 명시
- 검증주체: 검수자+보조기기
- 중요도: 핵심
- source_ids: S06;S07;S26

## A09 색 이외 의미 단서

- 분류: 조건부
- 적용조건: 정답, 선택, 오류, 범주에 색을 사용
- 근거지위: WCAG 1.4.1 A
- 검사방법: 흑백과 텍스트 상태를 확인
- 통과조건: 색 없이 필요 정보를 구별
- 예외: 색을 금지하지 않음
- 검증주체: 검수자
- 중요도: 높음
- source_ids: S80

## A10 텍스트와 필수 UI 대비

- 분류: 조건부
- 적용조건: 텍스트, 조작, 상태
- 근거지위: WCAG 1.4.3, 1.4.11 AA
- 검사방법: 실제 상태의 전경, 배경 비율을 측정
- 통과조건: 일반 텍스트 4.5:1, 큰 텍스트 3:1, 필수 UI 3:1과 예외를 대조
- 예외: 장식, 비활성 등 예외는 별도; 수치가 교육 최적값은 아님
- 검증주체: 검수자
- 중요도: 높음
- source_ids: S03;S05

## A11 확대와 주변 컨트롤 배치

- 분류: 조건부
- 적용조건: 텍스트 및 유동화 콘텐츠
- 근거지위: WCAG 1.4.4, 1.4.10 AA
- 검사방법: 200% 텍스트 및 320 CSS px 상당 폭 등을 적용하여 시험
- 통과조건: 지시, 핵심 컨트롤의 정보 손실이 없음
- 예외: 본질적인 2차원 게임 영역은 reflow 예외 가능; 주변 UI는 별도
- 검증주체: 검수자+실기기
- 중요도: 높음
- source_ids: S81;S04

## A12 이미지의 문맥상 대체 정보

- 분류: 조건부
- 적용조건: 정보 또는 기능 이미지
- 근거지위: WCAG 1.1.1 A
- 검사방법: 본문, 대체 텍스트, 시각 자료의 목적을 대조
- 통과조건: 의미, 용도를 동등하게 제공
- 예외: 장식은 빈 대안 허용; 평가 정답 누출은 목표 조건과 대조
- 검증주체: 검수자+교사
- 중요도: 높음
- source_ids: S02;S42
