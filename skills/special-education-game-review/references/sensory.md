# 감각·시간

각 항목의 근거 지위·적용 조건·예외를 함께 읽는다. 기준 원문은 2026-10-05 조사에서 가져왔고 제품 합격 판정은 포함하지 않는다. [출처 원장](sources.json)에서 source_ids의 URL·절·판본·한계를 확인한다. 최신 개정, 법적 적용 또는 세부 수치가 결과를 바꾸면 해당 발행기관 원문을 다시 확인한다.

## S01 목표와 무관한 시간 장벽 조절

- 분류: 조건부
- 적용조건: 콘텐츠 시간 제한
- 근거지위: WCAG 2.2.1 A 및 XAG 권장
- 검사방법: 끄기, 조절, 연장을 실제 실행
- 통과조건: 적용되는 표준의 시간 조절 선택지를 충족
- 예외: 대안이 없는 실시간 사건, 연장 시 활동이 무효화되는 본질적 시간 제한, 20시간보다 긴 시간 제한은 각 예외 조건을 대조
- 검증주체: 검수자+교사
- 중요도: 핵심
- source_ids: S52;S47

## S02 자동 움직임 및 갱신 제어

- 분류: 조건부
- 적용조건: 자동 움직임 또는 갱신
- 근거지위: WCAG 2.2.2 A
- 검사방법: 움직임 지속, 동시 콘텐츠, 갱신 유형을 확인하고 멈춤을 실행
- 통과조건: 해당 유형의 멈춤, 정지, 숨김 또는 빈도 조절을 충족
- 예외: 자동 움직임의 5초 조건을 자동 갱신에 일괄 적용하지 않음
- 검증주체: 검수자
- 중요도: 높음
- source_ids: S53

## S03 비필수 카메라와 움직임 조절

- 분류: 조건부
- 적용조건: 3D 카메라, 배경 진동, 움직임
- 근거지위: 게임 접근성 권장
- 검사방법: 감소, 정지 설정 및 활동 보존을 시험
- 통과조건: 비필수 움직임을 줄여도 핵심 활동이 가능
- 예외: 모든 활동 동결을 표준 의무로 강제하지 않음
- 검증주체: 검수자+학생관찰
- 중요도: 높음
- source_ids: S48;S51

## S04 깜박임 기준과 검사 범위

- 분류: 조건부
- 적용조건: 깜박임 발생 가능
- 근거지위: WCAG 2.3.1 A 및 게임 권장
- 검사방법: 전체 상태를 캡처한 후 빈도, 면적, 명도, 적색을 검사
- 통과조건: 해당 WCAG 문구 및 문턱으로 판정
- 예외: 육안이나 경고만으로 안전을 확정하지 않음; 발작 위험 제로 선언 금지
- 검증주체: 검수자+전문도구
- 중요도: 핵심
- source_ids: S54;S49

## S05 핵심 소리 정보 대안

- 분류: 조건부
- 적용조건: 소리로 지시, 결과, 상태를 전달
- 근거지위: 게임 접근성 권장 및 KWCAG
- 검사방법: 음소거 상태에서 과제를 수행
- 통과조건: 필수 정보가 시각, 텍스트 등으로 동등하게 전달됨
- 예외: 소리 자체가 목표면 측정 조건과 다른 참여 경로를 구분
- 검증주체: 검수자+교사
- 중요도: 높음
- source_ids: S50;S21

## S06 재생 제어와 실제 음성

- 분류: 조건부
- 적용조건: 음성, TTS, 음악 사용
- 근거지위: 교육자료 운영 검수 제안
- 검사방법: 음소거, 다시 듣기, 정지를 실행하고 실제 용어의 발음을 청취
- 통과조건: 핵심 말이 정확하고 필요한 제어에 도달 가능
- 예외: 파일 생성 확인은 청취 완료가 아님; 채널별 음량은 필요시 권장
- 검증주체: 검수자+교사
- 중요도: 높음
- source_ids: S51;S21
