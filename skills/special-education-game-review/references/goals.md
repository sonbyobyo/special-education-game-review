# 목표·교수·평가

각 항목의 근거 지위·적용 조건·예외를 함께 읽는다. 기준 원문은 2026-10-05 조사에서 가져왔고 제품 합격 판정은 포함하지 않는다. [출처 원장](sources.json)에서 source_ids의 URL·절·판본·한계를 확인한다. 최신 개정, 법적 적용 또는 세부 수치가 결과를 바꾸면 해당 발행기관 원문을 다시 확인한다.

## G01 목표, 행동, 증거 정렬

- 분류: 공통
- 적용조건: 학습 목적을 표방하는 게임
- 근거지위: 근거 기반 운영 제안
- 검사방법: 목표별 학생 행동, 활동, 성공 판정을 대조
- 통과조건: 확인된 목표 또는 교사 제안 상태와 관찰 증거를 연결
- 예외: 공식 IEP 목표나 성취기준이 미제공·미확인 상태이면 생성하지 않으며 확인 필요 상태를 표시
- 검증주체: 교사+검수자
- 중요도: 핵심
- source_ids: S33;S40

## G02 목표와 부수 접근 요구 구분

- 분류: 공통
- 적용조건: 읽기, 말하기, 정밀 조작, 시간 요구가 있음
- 근거지위: 근거 기반 운영 제안
- 검사방법: 요구를 목표 기술, 접근 수단, 목표 변경으로 분류
- 통과조건: 지원 후 확인 가능한 학습 범위를 설명
- 예외: 특정 기술 자체가 목표면 대체가 목표를 변경할 수 있음
- 검증주체: 교사
- 중요도: 핵심
- source_ids: S33;S34

## G03 문제 및 자료 정확성

- 분류: 공통
- 적용조건: 문제, 정답, 수량, 관계, 절차를 제시
- 근거지위: 프로젝트 검수 제안
- 검사방법: 문항별 자료, 실제 구성·수량, 정답, 판정, 지시를 대조하고 과제에 맞는 오답·반례·회복 경로를 실행
- 통과조건: 불일치 및 모호한 성공 판정이 없음
- 예외: 창작형에 유일 정답을 요구하지 않음
- 검증주체: 교사+검수자
- 중요도: 핵심
- source_ids: S33;S40

G03의 실제 구성 반례와 창작형 예외는 [활동 검사 절차](activity-checks.md)를 따른다. 계산 정답과 구성 상태가 다른 경우를 구분하며, 정상 경로 완료만으로 자료 정확성을 통과시키지 않는다.

## G04 게임 점수와 성취 구분

- 분류: 조건부
- 적용조건: 점수로 능력, 성취를 보고함
- 근거지위: 측정 원칙 기반 제안
- 검사방법: 점수 산식, 목표 연결, 대상별 타당성, 보고 문구를 확인
- 통과조건: 미검증 점수는 관찰값으로 보고
- 예외: 검증된 특정 모델은 그 대상, 목적 범위에서 활용
- 검증주체: 교사+측정담당
- 중요도: 핵심
- source_ids: S40;S44;S45

## G05 접근 조건과 내용 촉구 구분

- 분류: 조건부
- 적용조건: 힌트, TTS, AAC, 교사 지원이 제공됨
- 근거지위: 측정, 교수 원칙 기반 제안
- 검사방법: 접근 설정, 정답 단서, 타인 입력 시점을 구분
- 통과조건: 접근 도구를 사용한 독립 반응과 정답 도움 반응을 분리
- 예외: 도구 이름만으로 판정하지 않음; 목표 기술 대행 여부를 확인
- 검증주체: 교사+검수자
- 중요도: 핵심
- source_ids: S34;S36;S40

## G06 최초 응답과 내용 촉구·정답 공개 후 응답 구분

- 분류: 조건부
- 적용조건: 재시도, 정답 공개, 내용 촉구 후 성공을 기록
- 근거지위: 근거 기반 운영 제안
- 검사방법: 최초 응답, 접근 지원 조건, 내용 촉구, 정답 공개, 재시도 경로를 확인하고 실행
- 통과조건: 접근 지원 조건을 함께 기록하고 최초 응답과 내용 촉구·정답 공개 후 반응을 혼합하지 않음
- 예외: 학습용 재시도 허용; 불필요한 학생 이력의 상시 저장은 불필요
- 검증주체: 검수자+교사
- 중요도: 높음
- source_ids: S40;S43;S45

## G07 의도하지 않은 정답 단서

- 분류: 조건부
- 적용조건: 평가형 선택 문항
- 근거지위: 문항 설계 근거의 게임 적용 추론
- 검사방법: 색, 테두리, 길이, 대체 텍스트, 이미지, 정답 강조를 대조
- 통과조건: 목표와 무관한 단서로 정답 식별이 불가
- 예외: 그림 판별 목표의 정당한 그림 정보는 제거하지 않음
- 검증주체: 교사
- 중요도: 높음
- source_ids: S42;S40

## G08 낭독의 목표별 적합성

- 분류: 조건부
- 적용조건: TTS로 문자 과제에 응답
- 근거지위: 측정 원칙 기반 제안
- 검사방법: 낭독 범위가 해독, 이해, 정보 활용 중 무엇을 대신하는지 분석
- 통과조건: 낭독 조건과 학생이 실제 수행한 기술의 범위를 명시하고 TTS가 대신 수행한 목표 기술을 학생 성취로 보고하지 않음
- 예외: TTS 일괄 금지나 일괄 효과 판정은 없음
- 검증주체: 교사
- 중요도: 핵심
- source_ids: S34;S40;S46

## G09 피드백의 다음 행동

- 분류: 조건부

## G10 단계별 수행 지원

- 분류: 조건부

## G11 촉구 감소와 접근 도구 보존

- 분류: 조건부
- 적용조건: 독립 수행 향상을 주장
- 근거지위: 교수 및 AT 근거 기반 제안

- 통과조건: 정답 반응 촉구와 응답 경로를 구별
- 예외: 하나의 촉구 위계 강제 금지; 목표 기술 대행은 별도 평가
