# 의사소통·존엄

각 항목의 근거 지위·적용 조건·예외를 함께 읽는다. 기준 원문은 2026-10-05 조사에서 가져왔고 제품 합격 판정은 포함하지 않는다. [출처 원장](sources.json)에서 source_ids의 URL·절·판본·한계를 확인한다. 최신 개정, 법적 적용 또는 세부 수치가 결과를 바꾸면 해당 발행기관 원문을 다시 확인한다.

## P01 도움, 쉬기, 거절 의사 표현

- 분류: 공통 적용여부 확인
- 적용조건: 활동 중 도움·쉬기·거절·선택 변경 등의 의사표현이 필요함
- 근거지위: NJC, ISAAC 원칙의 게임 적용 제안
- 검사방법: 게임 UI 또는 기존 AAC, 합의 신호, 교사 응답을 시연
- 통과조건: 의사표현을 인지하고 응답하며, 해당하는 경우 활동 복귀 조건을 명시
- 예외: 모든 게임에 3개 버튼 또는 새 AAC 판을 강제하지 않음
- 검증주체: 교사+학생관찰
- 중요도: 핵심
- source_ids: S28;S29;S30
